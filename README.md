# FoodBridge 2.0

Install: `npm install`; copy `.env.example` to `.env`; add your Hindsight API key; run `npm start`.

Features: fresh-meal funding, wedding/function leftovers, NGO ratings, Hindsight retain/reflect backend, volunteer map area, no-volunteer NGO pickup fallback, reminder/vibration demo.

Google Maps requires a Maps API key for an embedded interactive map; the demo currently opens Hyderabad in Google Maps."# FoodBridge"
